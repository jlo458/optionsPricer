# option-pricer

A **C++17** library for pricing vanilla equity options.

## What it is

Three methods for the **same** contract specification, checked against identities and against each other:

1. **Black–Scholes–Merton** closed form (European call/put) with Greeks: delta, gamma, vega, theta, rho.
2. **Cox–Ross–Rubinstein** binomial tree (European and American early exercise).
3. **Monte Carlo** under GBM (European only): risk-neutral sample mean of discounted payoff, with standard error and a seedable RNG.

Contract parameters: spot \(S\), strike \(K\), rate \(r\), continuous dividend yield \(q\) (may be 0), volatility \(\sigma\), expiry \(T\), call/put, European/American.

## What it is not

- Not a QuantLib wrapper, and not fitted to market option quotes.
- No barriers, Asians, local vol, rate curves, live market data, GPU, SIMD, GUI, or neural nets.
- A study / portfolio artefact only — not a live pricing or execution stack.

## Formulae (brief)

**Black–Scholes–Merton** (continuous yield \(q\)):

\[
d_{1,2}=\frac{\ln(S/K)+(r-q\pm\tfrac12\sigma^2)T}{\sigma\sqrt{T}},\quad
C=Se^{-qT}\Phi(d_1)-Ke^{-rT}\Phi(d_2),\quad
P=Ke^{-rT}\Phi(-d_2)-Se^{-qT}\Phi(-d_1).
\]

The normal CDF uses `std::erfc` from the C++17 standard library (no Boost.Math).

**CRR binomial**: \(u=e^{\sigma\sqrt{\Delta t}}\), \(d=1/u\), risk-neutral \(p=(e^{(r-q)\Delta t}-d)/(u-d)\). Work backwards from expiry; for American options take the max of continuation and intrinsic at each node.

**Monte Carlo** (European): \(S_T=S\exp\bigl((r-q-\tfrac12\sigma^2)T+\sigma\sqrt{T}\,Z\bigr)\), \(Z\sim N(0,1)\). Estimator \(\widehat{V}=e^{-rT}\frac1N\sum_i\mathrm{payoff}(S_T^{(i)})\), with sample standard error of the mean.

## Build

Requires **CMake 3.16+** and a C++17 compiler. Catch2 is fetched automatically.

**Unix / macOS / WSL**

```bash
cd option-pricer
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=g++
cmake --build build -j
ctest --test-dir build --output-on-failure
```

If your default `c++` is Clang without a working `libstdc++` link path, pass `-DCMAKE_CXX_COMPILER=g++` as above (or use a full Clang+libc++ toolchain).

**Windows (Visual Studio generator)**

```bat
cd option-pricer
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

MSVC warning flags differ from GCC/Clang; the project enables `-Wall -Wextra -Wpedantic -Werror` on GCC/Clang-style compilers.

## CLI

```bash
./build/pricer --type call --exercise european --S 100 --K 100 --r 0.05 --q 0 --sigma 0.2 --T 1 --method bs
./build/pricer --method binomial --steps 500
./build/pricer --method mc --paths 100000 --seed 42
```

- `bs` prints price and Greeks.
- `binomial` prints price (`--steps`, default 500).
- `mc` prints price and `stderr` (`--paths`, `--seed`).

Invalid inputs (e.g. \(\sigma\le 0\), American + MC) exit with a clear error message.

## Tests (non-negotiable checks)

- Put–call parity on BS and on European binomial.
- BS call delta vs central bump-and-revalue.
- Deep ITM/OTM limits (call \(\to Se^{-qT}\) as \(K\to 0\), etc.).
- European binomial \(\to\) BS as steps increase (50 / 400 / 1000).
- American call with \(q=0\) equals European call; American put ≥ European put.
- MC: fixed seed, absolute error vs BS falls from 10k → 100k paths; stderr shrinks ~\(1/\sqrt{N}\).
- Invalid inputs throw / CLI errors clearly; American + MC rejected.
